# Working notes

## How to reply to Michael

End every message with a numbered **DO THIS** list: the exact commands or
actions, in order, and nothing else in it. If there is no action, say
"Nothing to do - waiting on X" in one line.

Rules:

- One path, not three. Pick the best option and say so. Alternatives
  only when the first one might genuinely fail, and then as a clearly
  labelled fallback underneath.
- Findings and reasoning go ABOVE the DO THIS list, kept short. Anything
  that is not a decision he has to make or an action he has to take is
  probably too long.
- Never mix an instruction into a paragraph of explanation. If he has to
  hunt for the command, the message failed.
- Say plainly when something is blocked and whether it blocks him or
  only me.
